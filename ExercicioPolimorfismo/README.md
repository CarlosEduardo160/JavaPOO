# Exercício de Polimorfismo em Java

---

Este exercício demonstra o uso de **polimorfismo** utilizando **classes abstratas** em Java.
O sistema simula diferentes formas de pagamento, onde cada tipo possui sua própria implementação do método responsável por processar o pagamento.

A classe base define um comportamento comum, enquanto as subclasses implementam esse comportamento de maneiras diferentes.

---

## Objetivo do Exercício

Demonstrar como o **polimorfismo** permite que diferentes objetos sejam tratados através de um mesmo tipo (`Pagamento`), enquanto cada classe mantém seu próprio comportamento.
