# Exercício de Herança em Java

---

Exercício simples com foco no conceito de herança.

O objetivo é representar diferentes tipos de funcionários de uma empresa. Todos os funcionários possuem informações básicas em comum, mas cada tipo possui **regras diferentes para cálculo de bônus**.

---
# Conceitos praticados

Este exercício foi desenvolvido para praticar:

* Herança (`extends`)
* Construtores em classes filhas
* Uso de `super`
* Sobrescrita de métodos
* Reutilização de código
* Organização de classes em um sistema simples
