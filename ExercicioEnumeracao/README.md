# Exercício – Controle de Status de Pedido com Enum (Java)

## Objetivo

Praticar o uso de **enumerações (`enum`) em Java** para representar estados fixos de um sistema, além de aplicar **regras simples de negócio** utilizando esses estados.

O exercício simula um pequeno sistema de **controle de status de pedidos**.

---

## Conceitos praticados

- Enum (`enum`)
- Encapsulamento
- Comparação de enums com `==`
- Regras de transição de estado
- Organização básica de classes
